# 実写動画 自動モザイク — 事前調査レポート

調査日: 2026-08-22
対象: 実写動画のみ（静止画・二次元は対象外）
目的: 刑法175条コンプライアンス（局部の自動モザイク付与）ツールの自作にあたる事前調査

## 0. 結論サマリ

| 問い | 答え |
|---|---|
| 完成品のOSSはあるか | **ない**。付与(add)側で実写動画に対応した実用OSSは存在しない |
| 商用モデレーションAPIは使えるか | **全滅**。局部の座標を返すベンダーが0社 |
| 市販編集ソフトで自動化できるか | **できない**。すべて「人がマスクを打って追尾させる」半自動 |
| 局部検出の既製重みは商用利用できるか | **ほぼ不可**。Ultralytics YOLO由来＝上流AGPL-3.0 |
| 学習データは入手できるか | **できない**。公開データセットは事実上ゼロ、自前構築が前提 |
| 全自動で焼き込む設計は妥当か | **妥当でない**。業界の実運用が「人手の全編チェック」前提 |

現実解は「全フレームで候補領域を提示し、人間の全編チェックを高速化するツール」。
「漏れゼロの全自動」は業界の誰も達成していない。

### 1-2. NudeNet の検出クラス

18クラス中、175条の対象範囲と一致するもの:

```
FEMALE_GENITALIA_EXPOSED, MALE_GENITALIA_EXPOSED,
FEMALE_GENITALIA_COVERED, ANUS_EXPOSED, ANUS_COVERED
```

クラス設計が用途にほぼ一致しているのが最大の利点。

弱点:
- bbox止まり（マスクなし）
- 既定 `320n` は入力320px。1080p/4Kで小さく写る局部を落とす → **`640m` を必ず使う**
- Issue #117: Python版がwebデモより検出率が低い（前処理のアスペクト比不一致＋閾値の差）。web相当の conf 0.4 / NMS 0.25 が良好との報告
- 学習スクリプト・データセットとも非公開（#192, #162）→ 自前ドメインへのファインチューン不可
- ライセンス照会 Issue #197/#198/#200 が**すべて作者未回答のまま**

### 1-3. DeepMosaics の動画パイプライン（設計として参考になる点）

```
ffmpeg で全フレーム画像展開（既定jpg）
 → 全フレーム推論、ROIマスクを全部ディスク保存
 → filt.position_medfilt(positions, window=7)
 → マスク描画
 → ffmpeg image2video (libx264) → 音声を別途マージ
```

踏襲する価値があるもの:
- resume機構（`step.json` + `.npy` で中断復帰）— 長尺では必須
- `filt.less_zero()` の検出ゼロ区間の埋め方
- `position_medfilt()` の外れ値判定条件（`0.8 < x_filt/x < 1.2` かつ `0.6 < area_filt/area < 1.4`）
- `mosaic.addmosaic()` のモード（`squa_avg` / `squa_avg_circle_edge` / `rect_avg`）と自動モザイクサイズ算出

丸ごと採用すべきでない理由:
- PyTorch 1.x / caffe2 依存。環境構築が最大の失敗要因（Issue #58/#31/#107/#117/#134 が全部これ）
- 中間jpg + libx264 CRF無指定 + mp3→aac の**三重再エンコードで画質・音質が確実に劣化**
- 複数音声トラック・字幕・チャプタが消える
- VFR素材でA/Vズレのリスク
- 2024年で更新停止（#101 "Is DeepMosaics abandonware at this point?" がopenのまま）
- GPL-3.0の伝播

## 2. ライセンス — 最大の障壁

| 対象 | 表記 | 実効的な制約 |
|---|---|---|
| DeepMosaics | GPL-3.0 | コード流用→自作物もGPL。バイナリ配布時にソース提供義務 |
| NudeNet（リポジトリ） | AGPL-3.0 | **ネットワーク越しの提供でもソース開示義務**。SaaS化不可 |
| NudeNet（PyPI wheel） | MIT表記 | リポジトリと矛盾。Issue #198で指摘されたが作者未回答。MITを根拠にした商用配布は危険 |
| Ultralytics YOLO由来の重み全般 | 上流AGPL-3.0 | **ファインチューン済み重みも派生物**とみなすのがUltralytics側の解釈。モデルカードが`apache-2.0`と書いていても**上流の制約は上書きできない**（EraX系がこれ） |
| NSFW-API/NSFW_Segmentation | **未指定** | 未指定＝全権利留保。**利用許諾が存在しない**ので商用不可と見なすべき |

### 分岐

**A. 社内・自己使用のみ**（成果物の動画だけを配布し、ツール自体は配布しない）
→ AGPL/GPLでも**開示義務は発生しない**。最も安全かつ低コスト。

**B. ツールを配布 or SaaS提供**
→ Ultralytics Enterprise License購入、または Apache-2.0系アーキで**自前アノテーション・自前学習**。
NudeNetは学習スクリプト・データセットとも非公開なので、この道はアノテーションから始まる。

Ultralytics派生重みのAGPL伝播について法的に確定した判例はなく、モデル重みがGPL上の「派生物」に当たるかは未確立。**弁護士確認を推奨する領域**。

## 3. 商用モデレーションAPI — 全滅

### 3-1. 使えない理由（3点）

1. **局部の座標を返すベンダーが0社**。すべて分類スコアまたはラベル止まり。モザイクを「どこに」置くかが決まらない
2. **動画は 1 FPS サンプリングが前提設計**。30fps全フレームが要る用途とは設計思想が根本的に違う
3. 全フレームを画像APIに投げるとコストが破綻する

### 3-2. 比較

| ベンダ | 動画 | サンプリング | 座標 | クラス粒度 | AUPでアダルト可否 |
|---|---|---|---|---|---|
| Hive Moderation | あり | **既定1FPS**。引き上げ可だが公式が「精度は必ずしも改善せずコスト増」と明記 | **なし** | 最も細かい（Bulges, Breast, Genitals, Butt のbeta headあり） | **グレー**。ToSに"pornographic"禁止条項、一方でDashboard規約は処理前提。矛盾、要個別合意 |
| Sightengine | あり | 公開仕様なし | **なし**（bboxは顔・ナンバープレート・PIIのみ） | スコアのみ、部位単位でない | **6社中もっともクリーン**。禁止はCSAMと違法行為のみ |
| AWS Rekognition | あり | 公式が「Timestampは個別フレームまで正確とは保証しない」と明記 | **なし**（geometryフィールドが存在しない） | ラベル階層のみ | 明示禁止なし |
| Google Video Intelligence | あり | 記載なし | **なし** | **最も粗い**。5段階likelihoodのみ | 明示禁止なし |
| Azure AI Content Safety | **動画非対応** | — | — | — | — |
| Clarifai | あり | 確認できず | **なし** | sfw/nsfwの2クラスのみ | 確認できず |

### 3-3. コスト試算

Hiveの$3/1,000画像で30fps・30分作品を全フレーム投げると54,000フレーム → **約$162（約24,000円）／1本**。
国内の人手外注相場（30分で7,000〜8,000円）の**3倍**。座標も返らないのに。

## 5. 法的前提（公開情報の整理であり法的助言ではない）

### 5-1. 条文（2022年改正・2025年6月1日施行後の現行条文）

> **刑法 第百七十五条（わいせつ物頒布等）**
> わいせつな文書、図画、電磁的記録に係る記録媒体その他の物を頒布し、又は公然と陳列した者は、二年以下の拘禁刑若しくは二百五十万円以下の罰金若しくは科料に処し、又は拘禁刑及び罰金を併科する。電気通信の送信によりわいせつな電磁的記録その他の記録を頒布した者も、同様とする。
> ２　有償で頒布する目的で、前項の物を所持し、又は同項の電磁的記録を保管した者も、同項と同様とする。

**条文中にモザイクに関する規定は一切ない。** タイル寸法・面積率・処理方法の定めも存在しない。

### 5-2. 主要判例

| 事件 | 要旨 | モザイクとの関係 |
|---|---|---|
| チャタレー事件（最大判 昭32.3.13） | わいせつの定義: 「徒らに性欲を興奮又は刺激せしめ、かつ、普通人の正常な性的羞恥心を害し、善良な性的道義観念に反するもの」 | 基本枠組み。修正の程度には触れない |
| 四畳半襖の下張事件（最判 昭55.11.28） | **作品全体との関連で判断**すべき。「主として読者の好色的興味にうったえるものと認められるか否か」 | 「局部が見えているか」だけで決まらない根拠 |
| メイプルソープ事件（最判 平20.2.19） | 美術的評価、写真集全体に占める比重（384頁中19頁）、構成等から好色的興味にうったえるものではないと認定 | 芸術性等の緩和要素が総合考慮される |
| **松文館事件** | 「網掛けが非常に薄く、ほとんど透けて見えるため、**性器の形状がほぼ完全に把握できる**」状態は修正として不十分 | **実務で最も参照される基準**。「性器の形状が把握できるか否か」が参考指標 |
| **FLMASK事件** | モザイク除去ツール配布サイトへのリンク掲載につき幇助が成立、懲役1年・執行猶予3年 | **「復元容易性」で修正済みでもアウトになりうる** |

### 5-3. 「モザイクをかければ適法」ではない — 6つの理由

1. **法令に数値基準は存在しない。** 「何画素なら合法」を法令から導けない
2. **わいせつ性は作品全体の総合判断。** 松文館の基準は判断の一要素にすぎない
3. **実務は捜査機関の運用慣行に依存。** 「性器の形状が把握できないように修正されていれば犯罪とみなさない」という慣行はあるが、**その法理上の根拠は曖昧**とされる
4. **実際に基準を作っているのは自主規制団体とプラットフォーム。** しかもJCRCの審査基準は非公開、公開されている数値（FANZA第6条）は同人・静止画向けの別基準。**法令ではなく自主規制が実務基準になっている**構造
5. **復元可能性でひっくり返る。** FLMASK事件、および2021年10月に京都府警がAIでモザイクを改変した約12,000本の販売者を逮捕した事案。**可逆的な処理は設計段階で避けるべき論点**
6. **審査した側も刑事責任を負いうる**（ビデ倫事件）

### 5-4. 範囲外だが確認が必要な論点

- 頒布形態（有償／無償、国内／国外サーバ、限定公開・鍵アカウントの扱い）
- 出演者の同意、および **AV出演被害防止・救済法（2022年）** の適用関係
- 撮影・保存段階の適法性
- 自作ツールが「モザイク除去」に転用されないための設計上の配慮

**実際の運用開始前に、必ず刑事事件・コンテンツ法務に通じた弁護士に個別確認すること。**
